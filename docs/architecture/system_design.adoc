== Visão Geral

Este documento descreve a arquitetura da plataforma de processamento assíncrono de transações de leasing de máquinas, modelada sob os princípios da *Arquitetura Hexagonal (Ports & Adapters)* e dos padrões de resiliência distribuída *Transactional Outbox*, *Inbox Pattern (Idempotência)* e *Non-blocking Retry / Dead Letter Queue (DLQ)*.
