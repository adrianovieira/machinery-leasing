== 2. Escopo e Detalhamento da Execução

=== 2.1. Expansão de Testes Automatizados
1. **Teste de Integração do CLI de DLQ Replay (`src/tests/integration/test_dlq_replay_cli.py`)**:
   * Validar execução da interface de linha de comando (`dlq_replay.py`) com argumentos `--list` e `--replay-all`.
   * Verificar recuperação de mensagens do tópico `transactions.dlq.v1`, reinicialização de status no `inbox_events` e reenvio atômico para `transactions.created.v1`.
2. **Auditoria Geral de Testes de Contrato, Unitários e de Integração**:
   * Garantir que todas as branches e cenários críticos (idempotência, transactional outbox, retries exponenciais, DLQ, OpenTelemetry e métricas) executem em < 10 segundos com isolamento in-memory.

=== 2.2. Refatoração, Limpeza e Hardening de Código
1. **Auditoria de Código com Ruff**:
   * Executar `pipenv run ruff check --fix .` e `pipenv run ruff format .` em todos os módulos (`src/app/`, `src/tests/`, `scripts/`).
   * Garantir ordenação estrita de imports: (1) stdlib, (2) third-party, (3) local app.
2. **Polimento de Tipagem e Tratamento de Erros**:
   * Revisão de type annotations e docstrings em todas as classes e funções públicas.
   * Fechamento seguro de recursos e garantia de ausência de deadlocks.

=== 2.3. Consolidação Documental e Guia de Execução (README.md)
1. **Atualização do System Design (`docs/architecture/system_design.adoc`)**:
   * Incluir link e referência formal ao `ADR 005: Observabilidade com OpenTelemetry, Métricas Prometheus e Carga Locust`.
2. **Criação do README.md Principal**:
   * Apresentação da arquitetura e decisões de engenharia.
   * Guia "Como Executar":
     ** Subir infraestrutura (`docker compose up -d`).
     ** Aplicar migrations (`pipenv run alembic upgrade head`).
     ** Iniciar API HTTP (`pipenv run uvicorn src.app.entrypoints.api.main:app`).
     ** Iniciar Workers (`OutboxPublisherWorker`, `TransactionConsumerWorker`, `RetryConsumerWorker`).
     ** Executar CLI de DLQ Replay.
     ** Rodar testes e cobertura (`pipenv run pytest`).
     ** Rodar testes de carga com Locust (`pipenv run locust -f src/tests/performance/locustfile.py`).
